# pkgbadge

Self-hosted badge server for GitHub Container Registry. Scrapes GHCR package pages and the OCI registry API to serve [shields.io endpoint badges](https://shields.io/badges/endpoint-badge) with pull counts, versions, image sizes, and platform info.

## Pages

- [[Installation]]: Docker CLI, Docker Compose, building from source
- [[Configuration Reference]]: environment variables and package format
- [[Badge Usage]]: available badges and shields.io integration
- [[API Reference]]: HTTP endpoint, response format, status codes
- [[Troubleshooting]]: common issues and debugging
